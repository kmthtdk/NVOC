================================================================================
TROUBLESHOOTING
================================================================================

Backend Not Running:
  Error: Backend not responding on http://localhost:4000
  Solution: cd backend && npm run dev

Frontend Not Running:
  Error: Frontend not responding on http://localhost:3000
  Solution: npm run dev

Database Not Initialized:
  Error: ECONNREFUSED (port 3306)
  Solution: docker-compose up -d  OR  Initialize manually

Tests Timing Out:
  Error: Timeout waiting for response
  Solution: npx playwright test ... --timeout=60000

Port Already in Use:
  Error: listen EADDRINUSE
  Solution:
    # Linux/Mac: lsof -i :3000 | awk '{print $2}' | xargs kill -9
    # Windows PS: Get-Process | Where-Object Port -eq 3000 | Stop-Process -Force

View Full Logs:
  cat test-results/mac-address-test.log

Run with Debug:
  npx playwright test tests/mac-address.spec.ts --debug

KEY FINDINGS
================================================================================

Issue #1: POST /devices Ignores macAddresses Body (DEFECT)
  → Schema accepts it, but controller doesn't use it
  → Workaround: Use POST /devices/:id/mac endpoints
  → File: backend/src/controllers/device.controller.ts:142-152

Issue #2: No Global Duplicate MAC Constraint (DESIGN)
  → Same MAC can exist on different devices (intentional)
  → Only device-scoped uniqueness

Issue #3: Search MAC Hydration (TBD)
  → GET /devices/search may not include MACs
  → Test 2.2 documents actual behavior

Recommendation: Address Issue #1 before production deployment
